# 课安隐私政策

## 一、引言

**请在使用前仔细阅读。若你不同意，请不要注册或使用本平台。**

## 二、我们收集哪些信息

### 2.1 你主动提供的信息

| 类别 | 具体内容 | 是否必填 | 用途 |
|---|---|---|---|
| 账号信息 | **QQ 邮箱**、密码 | 必填 | 注册、登录、找回密码、接收验证码 |
| 资料信息 | 昵称、性别、头像、封面图 | 昵称必填，其余选填 | 展示个人主页与任务信息 |
| 学校信息 | 学校、校区 | 学校必填，校区为选填、由你自行填写（用于让同学更快找到你所在校区，不填不影响使用） | 判断同校范围 |
| 代课任务 | 课程名、日期、时间段、校区、教学楼与教室、是否上机、是否拍照、性别要求、酬谢、原因/要求/备注 | 视字段而定 | 发布任务、供他人申请 |
| 沟通内容 | 站内私信内容 | 选填 | 双方沟通 |
| 评价内容 | 星级、标签、文字 | 选填 | 信用与评价体系 |
| 举报与申诉 | 原因、补充说明、证据图片 | 视情况 | 处理举报与申诉 |
| 上传的图片 | 头像、封面、现场照片、证据图片 | 视情况 | 实现对应功能 |

### 2.2 你使用服务时自动收集的信息

| 类别 | 具体内容 | 用途 |
|---|---|---|
| 登录设备信息 | 设备名称、登录 IP、最近登录时间 | 账号安全、登录设备管理（可远程下线） |
| 操作与内容记录 | 任务状态变更、申请与取消记录、评价记录 | 实现业务流程、信用统计、纠纷处理 |
| 必要日志 | 请求时间、接口路径、错误信息、请求标识 | 故障排查与安全防护 |

### 2.3 我们**不会**收集的信息

- **不收集定位信息**（不使用 GPS；位置信息由你手动填写为校区/教学楼/教室）
- **不收集通讯录、短信、通话记录**
- **不收集身份证号、学号，手机号等身份证明信息**
- **不收集任何支付信息**（本平台不经手资金，酬谢由双方线下自行结算）

## 三、我们如何使用信息

3.1 用于**提供与改进服务**：注册登录、发布与申请任务、匹配与确认、私信沟通、评价与信用统计。

3.2 用于**账号与平台安全**：人机校验（防批量注册）、登录设备管理、识别与处置违规行为。

3.3 用于**通知**：站内通知与应用内未读提醒。**本平台目前不使用系统级推送**。

3.4 用于**客服与纠纷处理**：核对你提交的举报、申诉与相关证据。

## 四、我们如何共享信息

4.1 **我们不会出售你的个人信息。**

4.2 为实现功能，我们接入了以下第三方服务，它们可能接触必要的技术信息：

| 第三方 | 用途 | 涉及信息 |
|---|---|---|
| Cloudflare Turnstile | 登录/注册时的人机校验 | 请求 IP、浏览器/设备特征 |
| QQ 邮箱（SMTP 服务） | 发送邮箱验证码 | 你的 QQ 邮箱地址、验证码 |
| 自建对象存储（RustFS） | 保存上传的图片与文件 | 你上传的图片 |

4.3 在下列情况下我们可能提供必要信息：

- 依据法律法规、司法或行政机关的强制要求；
- 为保护用户或公众的人身、财产安全所必需；
- 处理举报、申诉与纠纷所必需（例如向当事方说明处理依据）。

4.4 其他用户能看到的信息：你的**昵称、头像、性别、学校/校区、信用与评价信息**，以及你主动发布的任务内容。**你的邮箱与手机号不会展示给其他用户。**

若你开启**隐私账号**，其他用户仅能看到你的头像、昵称与学校，且你不会出现在"可发起私信"列表中。

## 五、我们如何存储与保护

5.1 **传输安全**：客户端与服务端之间使用 HTTPS 加密传输。

5.2 **账号口令**：账号密码使用**不可逆的哈希算法（BCrypt）**加密存储，我们无法还原你的明文密码。

5.3 **访问控制**：对个人信息的访问实行权限控制，并记录必要的操作日志。

5.4 **登录设备管理**：你可以在"账号与安全"中查看登录设备并远程下线。

5.5 **请注意**：互联网环境并非绝对安全。请妥善保管账号密码，不要在不安全的网络环境下操作。若发现账号异常，请立即修改密码并联系我们。

## 六、信息保留期限

6.1 在为你提供服务所必需的期限内保留你的信息。

6.2 你注销账号后，我们将删除或匿名化你的个人信息，但法律法规要求保留的信息（如依法应当留存的记录）除外。

6.3 任务、评价等**与交易对方或平台信用体系相关的记录**，在你注销后可能以**去标识化**方式保留，用于信用与纠纷追溯。

## 七、你的权利

7.1 **查询与更正**：你可以在"我的"页查看并修改昵称、性别、头像、封面、学校、校区等信息。

7.2 **管理登录设备**：在"账号与安全"中查看并下线其他设备。

7.3 **删除**：你可以删除自己发布的内容。

7.4 若你对本政策有疑问、意见或投诉，可通过平台内举报与反馈入口联系我们。

## 八、未成年人保护

8.1 本平台面向在校学生。**若你未满 18 周岁**，请在监护人指导下阅读本政策，并在取得监护人同意后使用本平台。

8.2 我们建议未成年人不发布或承接涉及金钱往来的任务；如参与，应事先告知监护人。

8.3 若我们发现在未取得监护人同意的情况下收集了未成年人信息，将依法删除相关信息。

## 九、政策更新

9.1 我们可能适时修订本政策。修订后将在本平台公告，重大变更会以显著方式提示。

9.2 **在你继续使用本平台前，请留意并阅读更新后的政策。**
